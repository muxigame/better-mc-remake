## 账户与连接边界

启动器向原生终端提供现有账户 access bearer，账户页和原生好友 HTTPS
请求使用同一个 bearer。原账户 refresh family 和 DPAPI 存储继续使用。
不再另发终端 bootstrap、proof、ticket，也不创建或保存终端 CEF 账户
cookie；生产旧终端凭据发行接口返回 410。账户 token 不进入 Minecraft
网络包、JavaScript、URL、命令行或游戏环境变量。游戏网络只传公共
request/game-session UUID、UID 和状态。

Auth 的连接绑定仍要求现有账户 token、对应 UID、当前服务器监听器和
游戏会话同时匹配。源账户过期、撤销、切换及真实断线均验证失效边界。
Auth/Web/008 使用同一专用 SSO/社交服务鉴权密钥；密钥在服务器生成和
配置，未输出正文。生产 LoginGate 与 OP 同步继续关闭。
