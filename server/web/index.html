SYSTEM REQUIREMENTS

配置要求

整合包收录四百多个模组，比原版吃配置。最低配置指能稳定进游戏，推荐配置指画质开到中高、开光影也跑得动。

最低配置推荐配置
操作系统Windows 10 64 位（1809 及以上）Windows 11 64 位
处理器Intel Core i5-6500 / AMD Ryzen 3 1200Intel Core i5-12400 / AMD Ryzen 5 5600
内存8 GB16 GB
显卡512 MB 显存，支持 OpenGL 3.2独立显卡，4 GB 显存（GTX 1650 / RX 6600 及以上）
存储空间10 GB 可用空间20 GB 可用空间，固态硬盘
  • 首次安装需要下载约 3 GB，装完占用也是约 3 GB；余下的空间留给存档、光影和更新缓存。之后的更新只拉取发生变化的文件。
  • 游戏内存由客户端按物理内存自动分配：8 GB 的机器约分到 4 GB，16 GB 及以上才分得到整合包推荐的 8 GB。
  • 双显卡笔记本请在客户端「设置 → 显卡」里指定独立显卡。Windows 默认可能把游戏交给核显，表现是帧数怎么调都上不去。
